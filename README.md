# NFL Injury Factors Analysis



## Project Overview



NFL players face substantial physical demands throughout a season, but injury patterns may be associated with more than what happens during an individual play. Travel, recovery time, stadium environment, playing surface, weather, and the timing of a game within the season may all be related to when injuries appear.



This project uses publicly available NFL data to explore factors associated with player injuries during the **2009–2025 NFL seasons**.



Our analysis focuses on several questions:



1. Is travel distance associated with new NFL injury spells?

2. Do injury patterns vary across stadium locations?

3. Are injury patterns different on grass and artificial turf?

4. How do temperature and playing surface interact with injury occurrence?

5. Are injury patterns different when teams have short rest?

6. Do injury patterns change over the course of a season?

7. Have the relative frequencies of major injury types changed over time?



The project combines NFL injury reports, game schedules, stadium information, player data, and other game-level variables. We preprocess repeated weekly injury reports into unique **injury spells** and engineer additional features for travel distance, weather, playing environment, and rest.

## Data Sources



### NFL Data



The primary NFL datasets are accessed using the [`nflreadpy`](https://github.com/nflverse/nflreadpy) Python package, which provides access to data from the nflverse ecosystem.



The project downloads:



- **Injuries** — weekly NFL player injury reports

- **Schedules** — game schedules and contextual information such as teams, stadiums, rest days, temperature, wind, surface, and roof type

- **Snap counts** — player participation data

- **Players** — player information

- **Play-by-play data** — supported by the loading script but disabled by default because of its size



The data can be generated by running:



```bash

python Data/data_load.py
python Preprocessing/preprocessing.py
```
